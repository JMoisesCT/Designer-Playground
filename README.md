# Designer Playground

Kits para crear niveles de videojuegos 2D en Unity **sin programar**: dibujas el nivel, arrastras objetos, ajustas valores y le das a Play.

- Unity **6000.3** (Unity 6.3). Abre la carpeta del proyecto desde Unity Hub.
- Gráficos: Pixel Adventure 1. Sonidos: Kenney.

## Reglas

- Trabaja en **tu propio nivel**. No edites los niveles de ejemplo (`Nivel_01`) ni los de tus compañeros.
- No modifiques nada de `Assets/ThirdParty/`.
